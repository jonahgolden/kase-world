# Kase World

A game by Nova & Louie. You are Kase, the baby brother. Wreck the continent, scream at grown-ups,
throw poop, beat the boss, top the leaderboard.

Play: https://kase-world.kase-world.workers.dev

Controls: move with WASD or the left-side joystick, hold SPACE or SCREAM to charge a scream,
E or 💩 to throw, SHIFT or JUMP to jump.

Dev: `pnpm install && pnpm dev`. See `CLAUDE.md` for the layout and commands.
