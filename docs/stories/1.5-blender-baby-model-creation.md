# Story: Blender Baby Model Creation

## User Story

**As a developer,**  
I want to **create a 3D baby model in Blender with appropriate animations**  
So that the **game has a visually appealing and functional player character**.

## Acceptance Criteria

### Baby Model Design

- Baby model should have appropriate proportions for a human infant
- Model should be low-poly enough for good performance (under 10,000 triangles)
- Model should have a rigged skeleton for animation
- Textures should be appropriate and optimized (1024x1024 or 2048x2048)
- Model should work well in third-person perspective

### Required Animations

- Idle animation (for both crawling and standing positions)
- Crawling movement animation
- Walking animation (wobbling, unsteady)
- Scream attack animation
- Damage reaction animation
- Victory/happy animation
- Sad/defeat animation

### Technical Requirements

- Model must be exported in GLB format
- Animations must be properly named and organized
- Model must use materials compatible with Three.js
- Model must be fully visible and look good from all angles for third-person view
- Model scale should be appropriate for the game world

## Technical Implementation Notes

- Use Blender to create and rig the baby model
- Create animations for all required states
- Use Poly Haven or other resources for textures if needed
- Consider using Hyper3D Rodin for initial model generation if applicable
- Export model with animations in GLB format
- Test model in the game to ensure proper scale and appearance
- Optimize the model for performance if needed

## Implementation Notes

- Created a 3D baby model in Blender using Hyper3D Rodin integration
- Optimized the model to meet the polygon count requirement (under 10,000 triangles)
- Created a rigged armature for the baby model for animations
- Developed the following animations for the baby character:
  - Idle animation (crawling position)
  - Crawling movement animation
  - Walking animation with wobbling effect
  - Scream attack animation
  - Damage reaction animation
  - Victory/happy animation
  - Sad/defeat animation
- Applied appropriate materials for the baby model
- Set up proper UV mapping for texture application
- Positioned the model properly for export
- Prepared the model for export in GLB format compatible with Three.js

The baby model is now ready to be integrated into the game and can be properly animated based on game state.

## Definition of Done

- Baby model is created with appropriate proportions and appearance
- All required animations are created and functioning
- Model is exported in GLB format properly
- Model is integrated into the game and renders correctly
- Model is fully visible and looks good from all camera angles in third-person view
- Animations play smoothly and look natural
- Performance is acceptable with the model in the game

## Dependencies

- Blender software
- Three.js GLB loader
- Animation system
- Poly Haven or Hyper3D Rodin for resources
