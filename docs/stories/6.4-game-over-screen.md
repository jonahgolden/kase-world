# Story: Game Over Screen

## User Story

**As a player,**  
I want to **see a game over screen when my health reaches zero**  
So that I can **view my final score and choose to play again or exit**.

## Acceptance Criteria

### Game Over Detection

- Game should detect when baby's health reaches zero
- Game state should transition to "Game Over" state
- Gameplay should pause (no further damage/movement)
- Camera should transition to an appropriate view
- Death animation should play for the baby

### Game Over UI

- Game over screen should fade in clearly
- Final score should be prominently displayed
- New high score should be highlighted if achieved
- Leaderboard position should be indicated
- Performance statistics could be shown (time survived, enemies defeated)

### Player Options

- Clear option to play again (restart game)
- Option to return to main menu
- Option to exit game
- Options should be easily selectable
- Indication of which difficulty mode will be used if restarting

### Visual and Audio Elements

- Appropriate music for game over state
- Visual effects to emphasize game over state
- Animation for score tallying
- Transition effects between game and game over screen
- Different visual themes based on score achieved (optional)

## Technical Implementation Notes

- Implement game state system for detecting and handling game over
- Create game over UI screen
- Develop score finalization and high score checking
- Create transition animations and effects
- Implement restart and menu navigation logic
- Design audio cues for game over state
- Create statistics tracking and display
- Implement baby death animation

## Definition of Done

- Game correctly transitions to game over state when health reaches zero
- Game over screen displays with appropriate animations
- Final score is accurately calculated and displayed
- High score achievements are properly recognized
- Player can easily restart, return to menu, or exit
- Visual and audio elements enhance the game over experience
- All screen transitions are smooth and bug-free
- Game state is properly reset when restarting

## Dependencies

- Story 1.3: Baby Health System
- Story 6.2: Score System
- Story 6.3: UI and HUD Implementation
- Animation system for transitions
- Audio system for sound effects
