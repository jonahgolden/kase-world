# Story: Score System

## User Story

**As a player,**  
I want to **earn points and track my score during gameplay**  
So that I can **measure my performance and progress in the game**.

## Acceptance Criteria

### Score Calculation

- Points should be awarded for various in-game actions:
  - Defeating NPCs (points based on NPC type and difficulty)
  - Collecting/activating power-ups
  - Exploring new areas (optional)
  - Completing objectives (if implemented)
- Score calculation should be balanced for gameplay
- Different difficulty modes should affect score multipliers

### Score Display

- Current score should be clearly visible on the HUD
- Score increases should be animated with pop-up numbers
- Special achievements should have distinctive score animations
- High scores should be highlighted

### Score Persistence

- High scores should be saved between game sessions
- Leaderboard should display top scores with dates
- Scores should be categorized by difficulty mode
- Option to reset scores should be available

### Score Multipliers

- Implement score multiplier mechanics for skill-based play
- Consecutive defeats of NPCs could increase multiplier
- Special power-ups could temporarily increase multiplier
- Multiplier status should be clearly visible on HUD
- Multiplier should reset under certain conditions (taking damage)

## Technical Implementation Notes

- Create Score trait to track current score and multipliers
- Implement score calculation system
- Develop score display UI components
- Create animation system for score increases
- Implement persistence for high scores
- Design leaderboard UI
- Create multiplier mechanics and visual feedback
- Balance score values for different actions and difficulty levels

## Definition of Done

- Score is calculated correctly for all relevant actions
- Score display is clear and visually appealing on the HUD
- Score increases have appropriate animations and feedback
- High scores are saved correctly between sessions
- Leaderboard displays scores organized by difficulty
- Score multipliers function correctly with proper feedback
- Score balance feels rewarding and encourages skillful play
- Difficulty modes appropriately affect scoring

- Story 6.1: Game Difficulty Modes
