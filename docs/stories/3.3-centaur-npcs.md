# Story: Centaur NPCs

## User Story

**As a player,**  
I want to **encounter mythical centaur characters in the game world**  
So that I can **face unique and challenging opponents with special abilities**.

## Acceptance Criteria

### Centaur Appearance

- Centaurs should have a human upper body combined with a horse lower body
- Centaurs should be approximately 3-4x the baby's height
- Model should include appropriate centaur features with detailed textures
- Animations should include idle, trotting, galloping, attacking, damage reaction, and death

### Centaur Behavior

- Centaurs should patrol larger territories than other NPCs
- Centaurs should move faster than other NPC types
- Centaurs should be more perceptive, detecting the baby from greater distances
- When provoked, centaurs should use tactical approaches to attack

### Centaur Abilities

- Primary attack: Charge (high damage, requires distance to execute)
- Secondary attack: Rear kick (medium damage, close range)
- Special ability: Intimidating neigh (causes temporary movement slowdown)
- Movement: Fast galloping, can cover large distances quickly

### Spawn and Lifecycle

- Centaurs should be rarer than other NPCs, appearing in specific areas
- Centaurs should have higher health than other NPC types
- When defeated, centaurs should play an elaborate death animation
- Defeating a centaur should award a significant score bonus

## Technical Implementation Notes

- Create CentaurNPC trait and related systems
- Implement advanced AI for tactical movement and attacks
- Create centaur model with complex animations
- Implement special abilities and effects
- Add unique sound effects for centaur behaviors
- Balance centaur difficulty to be challenging but fair

## Definition of Done

- Centaur NPCs spawn correctly in designated areas
- Centaurs move naturally with appropriate animations
- Centaurs detect and engage the player with tactical approaches
- All attack types and special abilities function correctly
- Centaurs provide a challenging but balanced opponent
- Defeating centaurs feels rewarding with appropriate score bonus

## Dependencies

- Story 1.1: Baby Entity and Basic Movement
- Story 1.3: Baby Health System
- Story 2.1: Basic World Environment
- Story 3.4: NPC AI and Behavior
- Centaur 3D model and animations
- Sound effects for centaur behaviors
