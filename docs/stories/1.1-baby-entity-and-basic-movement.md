# Story: Baby Entity and Basic Movement

## User Story

**As a player,**  
I want to **control a baby character in third-person view**  
So that I can **navigate and interact with the game world**.

## Acceptance Criteria

### Baby Entity

- A baby entity must be created using the Koota ECS framework
- The baby should have a basic 3D representation (placeholder model until proper model is created)
- The baby entity should have all necessary traits for movement and interaction:
  - Transform trait for position and orientation
  - Movement trait for velocity and acceleration
  - Input trait for player controls
- The baby should be fully visible to the player in third-person perspective

### Basic Movement

- WASD keys for directional movement (forward, backward, left, right)
- Mouse for looking around (controlling direction)
- Space bar for jumping
- Movement should be smooth and responsive
- Basic collision detection to prevent moving through objects

### Camera

- Camera should follow the baby's movement
- Camera should provide a good view of the baby and its surroundings
- Smooth camera transitions during movement

## Technical Implementation Notes

- Extend the existing player entity implementation to represent a baby
- Implement appropriate movement physics (slower than the current ship)
- Create a baby-specific renderer component
- Implement camera system with appropriate positioning
- Implement basic collision detection

## Implementation Notes

- Created IsBaby trait to identify baby entities
- Updated actions.ts to add spawnBaby action with appropriate parameters (thrust: 0.3, damping: 0.85)
- Created a baby-renderer.tsx component with a simple placeholder 3D model
- Modified startup.tsx to spawn a baby entity instead of the default player
- Implemented third-person camera system in baby-camera.ts to provide a clear view of the baby
- Added collision detection in baby-collision.ts to prevent going through the floor or leaving boundaries
- Modified apply-input.ts to restrict baby movement to the horizontal plane
- Added a simple floor to the scene
- Integrated all systems in the game loop to enable movement, collision, and camera following
- Implemented jumping functionality:
  - Added jump property to Input trait
  - Created baby-jump.ts system to handle jump physics
  - Jump is triggered by pressing the space bar
  - Baby can jump up to 3 times its height (~0.9 units)
  - Added gravity physics to bring the baby down after jumping
  - Updated collision system to work seamlessly with jumping

The baby can now be controlled with WASD for movement, mouse for looking around, and space bar for jumping. The camera follows the baby from a third-person perspective, and collision detection prevents going through the floor or outside boundaries.

## Definition of Done

- Player can control the baby character with WASD and mouse
- Baby moves and rotates in response to player input
- Camera properly positioned to view the baby
- Basic collision detection prevents moving through objects
- Movement feels appropriate for a baby (not too fast/agile)
- Baby can jump with the space bar

## Dependencies

- Existing ECS framework
- Basic input system
- Temporary baby 3D model (placeholder)
