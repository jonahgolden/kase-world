# Story: Baby Vehicle Interaction

## User Story

**As a player,**  
I want to **seamlessly enter, control, and exit vehicles with my baby character**  
So that I can **utilize vehicles effectively as part of gameplay**.

## Acceptance Criteria

### Vehicle Entry and Exit

- Baby should be able to enter a vehicle when nearby and facing it
- Entry should be triggered by a key press (e.g., 'E')
- Entry animation should transition smoothly
- Exit should be triggered by the same or another key
- Baby should exit to a safe location near the vehicle
- Quick indicator should appear when near an enterable vehicle

### Baby in Vehicle

- Baby should be visibly positioned in the vehicle
- Baby's controls should now control the vehicle
- Baby should not be able to use the scream attack while in a vehicle
- Camera should adjust to appropriate position for driving
- Vehicle HUD elements should appear when in a vehicle

### Vehicle Impact Mechanics

- Vehicle collisions should cause impact to NPCs and objects
- Impact damage should be based on speed and vehicle mass
- Visual feedback should show collision impact
- Audio feedback should accompany collisions
- Impact with NPCs should affect their health

### Vehicle Limitations

- Vehicles cannot access all areas (size limitations)
- Vehicle fuel or battery could be limited (optional)
- Vehicles might have damage states that affect performance
- Baby health is still vulnerable in a vehicle (reduced damage)
- Special areas might require exiting the vehicle

## Technical Implementation Notes

- Create systems for baby-vehicle interaction
- Implement vehicle entry/exit mechanics
- Modify baby controller when in vehicle
- Adjust camera system for vehicle view
- Create impact damage system for vehicle collisions
- Design HUD elements for vehicle status
- Implement area restrictions for vehicles
- Develop feedback systems for vehicle interactions

## Definition of Done

- Baby can enter and exit vehicles smoothly
- Controls transition appropriately when entering/exiting
- Vehicle control feels natural and responsive
- Camera positioning works well for driving view
- Collisions and impacts work correctly with proper feedback
- Vehicle limitations create meaningful gameplay choices
- Indicators and HUD elements clearly show vehicle status
- Entry/exit points are clear to the player
