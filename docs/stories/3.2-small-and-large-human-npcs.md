# Story: Small and Large Human NPCs

## User Story

**As a player,**  
I want to **encounter human characters of different sizes in the game world**  
So that I can **interact with a variety of opponents with different challenges**.

## Acceptance Criteria

### Human Types

- Two distinct human NPC types:
  - **Small Humans**: Approximately 2x the baby's height
  - **Large Humans**: Approximately 4x the baby's height
- Each type should have distinct appearance and behaviors
- Models should include appropriate human features and proportions
- Animations should include idle, walking, attacking, damage reaction, and death

### Human Behavior

- Humans should move around their designated areas
- Small humans should be more agile but less powerful
- Large humans should be slower but more powerful
- Both types should react to the baby's presence appropriately
- When provoked, humans should pursue and attack the baby

### Human Abilities

- Small Humans:
  - Primary attack: Quick slap (low damage, fast attack speed)
  - Secondary ability: Dodge (can evade baby attacks)
  - Movement: Fast, agile movement
- Large Humans:
  - Primary attack: Stomp (high damage, slow attack speed)
  - Secondary ability: Taunt (draws baby's attention)
  - Movement: Slow but with longer reach

### Spawn and Lifecycle

- Humans should spawn in appropriate areas (houses, buildings, etc.)
- Population density should be balanced for gameplay
- Defeated humans should play death animation and disappear
- Small humans award lower score, large humans award higher score

## Technical Implementation Notes

- Create HumanNPC trait with size property
- Implement AI behavior systems for different human sizes
- Create human models with appropriate animations
- Implement attack patterns and damage calculations
- Add sound effects for human behaviors
- Set up spawning logic for different areas of the map

## Definition of Done

- Small and large human NPCs spawn correctly in appropriate areas
- Each human type exhibits distinct behaviors and attack patterns
- Humans react appropriately to player presence
- Attack animations and damage calculation work correctly
- Defeating humans awards appropriate score
- Human NPCs provide varied and interesting gameplay challenges

## Dependencies

- Story 1.1: Baby Entity and Basic Movement
- Story 1.3: Baby Health System
- Story 2.1: Basic World Environment
- Human character models and animations
- Sound effects for human behaviors
