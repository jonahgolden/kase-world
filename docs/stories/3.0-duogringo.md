# Story: Duogringo

## User Story

**As a player,**  
I want to **interact with the the Duogringo character in the game**  
so that I can **gameplay is more fun and challenging**.

## Acceptance Criteria

### Duogringo Appearance & Animation

- Use the glb file in `src/assets/duogringo.glb` for `duogringo-renderer.tsx`
- Follow patterns in `player-renderer.tsx` for displyaing the model and playing animations
- Duogringo should have a small "base" size, a scale of 0.2. Put this variable in a constant so we can adjust if necessary
- Animations are "Walk", "Idle", and "Attack"

### Duogringo Behavior

- Duogringo should move around the environment naturally
- When Duogringo is moving, the "Walk" animation plays. When Duogringo is idle, the "Idle" animation plays. When Duogringo attacks, the "Attack" animation should play
- Whenever Duogringo collides with a non-terrain collider, Duogringo Attacks. Duogringo should have a Cylinder collider.
- Duogringo tracks and follows the Player
- When Duogringo collides with the Player, Duogringo should Attack the player, which deals damage to the player.
- When Duogringo runs into terrain objects, he should jump high in a random direction. This will help him avoid getting stuck.

### Duogringo Abilities

- Primary attack: Pecking (medium damage, short range)
- Duogringo's Size, Speed, and Damage are all a function of his Power. His power is on a sliding scale. Duogringo's power increases when the Player screams, and decreases when he takes damge (from direct scream attack hits).

### Spawn and Lifecycle

- Duogringo spawns and the beginning of the game, and never goes away. He only gets less or more powerful.
