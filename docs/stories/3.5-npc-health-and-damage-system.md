# Story: NPC Health and Damage System

## User Story

**As a player,**  
I want **NPCs to have health systems and react realistically to damage**  
So that **combat feels impactful and rewarding**.

## Acceptance Criteria

### NPC Health Management

- Each NPC type should have appropriate health values:
  - Giant Chickens: Medium health
  - Small Humans: Low health
  - Large Humans: High health
  - Centaurs: Very high health
- Health should be tracked and updated in response to damage
- Health status should impact NPC behavior (fleeing when low)
- Health values should scale with game difficulty

### Damage Response

- NPCs should have visible reactions to taking damage
- Damage animations should vary based on damage amount and source
- NPCs should be briefly stunned when taking significant damage
- Visual indicators (like hit effects) should show when damage is dealt
- Sound effects should play when NPCs take damage

### Visual Health Indicators

- NPCs should have visual health indicators when targeted
- Health bars should appear when NPCs are damaged
- Appearance should degrade as health decreases (optional)
- Critical health state should be clearly visible

### Death and Rewards

- NPCs should have appropriate death animations
- Defeated NPCs should disappear after a short delay
- Defeating NPCs should award score points based on difficulty
- Death effects (particles, sounds) should provide feedback
- Score increases should be clearly communicated

## Technical Implementation Notes

- Create an NPCHealth trait with current and maximum values
- Implement damage application system for NPC entities
- Create visual feedback systems for damage and death
- Implement score calculation and award system
- Develop health indicator UI components
- Add impact animations and effects
- Balance health values across NPC types and difficulty levels

## Definition of Done

- All NPC types have functioning health systems
- NPCs react appropriately to taking damage
- Health indicators display correctly when needed
- Death animations and effects work properly
- Score is awarded correctly when NPCs are defeated
- Health values are balanced for appropriate challenge
- Combat feels impactful and satisfying
