# Story: Giant Chicken NPCs

## User Story

**As a player,**  
I want to **encounter giant chicken characters in the game world**  
So that I can **interact with and battle them as part of gameplay**.

## Acceptance Criteria

### Chicken Appearance

- Giant chicken should be approximately 3x the baby's height
- Model should include appropriate chicken features (wings, beak, comb, tail feathers)
- Texture should be colorful and distinct
- Animations should include idle, walking, attacking, damage reaction, and death

### Chicken Behavior

- Chickens should move around the environment naturally
- Chickens should have territory they patrol
- Chickens should react to the baby's presence when nearby
- When provoked, chickens should chase and attempt to attack the baby

### Chicken Abilities

- Primary attack: Pecking (medium damage, short range)
- Secondary behavior: Clucking (audio effect, no damage)
- Special ability: Feather flap (pushes the baby back)
- Movement: Faster than the baby's crawling speed, but slower than walking speed

### Spawn and Lifecycle

- Chickens should spawn in appropriate areas of the map
- There should be a reasonable number of chickens in the game world
- When defeated, chickens should play a death animation and disappear
- Defeated chickens should contribute to player score

## Technical Implementation Notes

- Create ChickenNPC trait and related systems
- Implement chicken AI for movement and targeting
- Create chicken model with appropriate animations
- Implement attack logic and damage calculation
- Add sound effects for chicken behaviors
- Set up spawning and lifecycle management

## Definition of Done

- Giant chicken NPCs spawn correctly in the game world
- Chickens move and behave according to defined patterns
- Chickens react to player presence and attack when appropriate
- Attack animations and damage work correctly
- Chicken death increases player score
- Chicken behaviors feel natural and appropriate

## Dependencies

- Story 1.1: Baby Entity and Basic Movement
- Story 1.3: Baby Health System
- Story 2.1: Basic World Environment
- Chicken 3D model and animations
- Sound effects for chicken behaviors
