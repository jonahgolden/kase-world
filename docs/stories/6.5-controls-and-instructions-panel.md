# Story: Controls and Instructions Panel

## User Story

**As a player,**  
I want to **access a controls and instructions panel**  
So that I can **learn how to play the game and understand all available interactions**.

## Acceptance Criteria

### Controls Documentation

- Complete list of all game controls:
  - Movement controls (WASD, mouse)
  - Crawl/walk toggle (Shift)
  - Scream attack (left mouse button)
  - Vehicle entry/exit (E)
  - Vehicle controls
  - Menu access (ESC)
  - Any other game-specific controls
- Controls should be clearly organized by category
- Controls should indicate which actions have cooldowns

### Instructions Content

- Basic gameplay objectives
- Explanation of health system
- Details on the scream attack mechanics
- Information about NPC types and their behaviors
- Power-up types and effects
- Vehicle usage instructions
- Score calculation explanation
- Difficulty modes description

### Panel Design and Interaction

- Panel should be accessible from the pause menu
- Option to view controls during gameplay (button/key)
- Panel should be clearly organized with tabs or sections
- Visual illustrations to accompany text where helpful
- Option to close panel and return to game
- Should be resizable or scrollable if content is extensive

### Accessibility

- Text should be in clear, readable font
- Contrast should be sufficient for readability
- Key information should be emphasized
- Keyboard shortcuts should be available for navigation
- Controls should show both keyboard and optional gamepad mappings

## Technical Implementation Notes

- Create UI components for the controls and instructions panel
- Implement panel access from pause menu and during gameplay
- Design tabbed or sectioned layout for organization
- Create visual illustrations for controls and concepts
- Implement keyboard navigation for accessibility
- Create system to detect and display current control bindings
- Design transition animations for panel opening/closing

## Definition of Done

- Controls panel is accessible from appropriate game states
- All game controls are accurately documented
- Instructions clearly explain all game mechanics
- Panel is well-organized and easy to navigate
- Visual design is consistent with the game style
- Panel can be easily opened and closed
- Content is complete and accurate
- Panel is accessible and readable
