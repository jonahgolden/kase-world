# Story: Game Difficulty Modes

## User Story

**As a player,**  
I want to **choose between different game difficulty modes**  
So that I can **tailor the challenge level to my preferences and skills**.

## Acceptance Criteria

### Three Difficulty Modes

- Implement three distinct difficulty modes:
  - **Explore Mode**: Game never ends, minimal threats
  - **Easy Mode**: Lower difficulty, suitable for casual play
  - **Hard Mode**: Higher difficulty, challenging experience
- Mode selection must be available before starting the game
- Selected mode should be clearly indicated

### Mode-Specific Adjustments

- **NPC Properties** should vary by mode:
  - Explore: Fewer NPCs, minimal aggression, lower damage
  - Easy: Moderate NPC count, standard aggression, standard damage
  - Hard: More NPCs, high aggression, increased damage
- **Power-up Distribution** should vary by mode:
  - Explore: Abundant power-ups
  - Easy: Regular power-up spawns
  - Hard: Sparser power-up spawns
- **Baby Properties** should adjust by mode:
  - Explore: Higher health, faster regeneration if applicable
  - Easy: Standard health and abilities
  - Hard: Lower health or slower regeneration

### Mode Selection UI

- Create a mode selection screen before game start
- Each mode should have clear description and visual indication
- Preview of difficulty level should be shown
- Selected mode should be saved for future sessions
- Option to change mode should be available in pause menu

### Explore Mode Specifics

- No game over condition in Explore mode
- Reduced consequences for taking damage
- Focus on exploration and environment
- Optional objectives or discoveries
- Reduced score mechanics (or none)

## Technical Implementation Notes

- Create GameMode trait to track current mode
- Implement difficulty scaling systems for NPCs and power-ups
- Develop UI for mode selection
- Create persistence for mode preference
- Implement mode-specific rule sets and behaviors
- Adjust spawn rates and entity properties based on mode
- Develop separate win/loss conditions for each mode
- Create appropriate feedback for mode changes

## Definition of Done

- All three difficulty modes are implemented and functional
- Mode selection UI works correctly
- NPC behavior, count, and damage scale appropriately with mode
- Power-up distribution adjusts based on selected mode
- Explore mode allows indefinite play without game over
- Easy and Hard modes provide appropriate challenge levels
- Mode selection persists between game sessions
- Modes can be changed from the pause menu
