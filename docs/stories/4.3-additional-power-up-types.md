# Story: Additional Power-up Types

## User Story

**As a player,**  
I want to **find and activate a variety of different power-up types**  
So that I can **experience diverse gameplay mechanics and strategic choices**.

## Acceptance Criteria

### Speed Boost Power-up

- Visually distinct with blue/cyan color and appropriate symbol
- Temporarily increases the baby's movement speed
- Works in both crawling and walking modes
- Duration should be clearly indicated
- Visual effects should show when active (trails, particles)

### Scream Power-up

- Visually distinct with yellow/orange color and appropriate symbol
- Temporarily enhances the baby's scream ability
- Can increase damage, range, or remove cooldown
- Duration should be clearly indicated
- Visual effects should show when active (enhanced scream effects)

### Invincibility Power-up

- Visually distinct with purple/rainbow color and star symbol
- Temporarily makes the baby immune to damage
- Short duration (3-5 seconds) for balance
- Distinctive visual effect on the baby when active
- Clear audio cue when active and when about to expire

### Score Multiplier Power-up

- Visually distinct with green color and appropriate symbol
- Temporarily multiplies score gains (2x, 3x)
- Duration should be clearly indicated
- Score numbers should show multiplier when active
- Visual feedback when score is multiplied

## Technical Implementation Notes

- Extend the power-up framework for each new power-up type
- Create specific traits for each power-up effect
- Implement timer system for duration-based effects
- Create visual assets and effects for each power-up type
- Develop sound effects for each activation
- Balance duration and effect strength for game balance
- Implement UI indicators for active power-ups

## Definition of Done

- Each power-up type is visually distinctive and recognizable
- Power-up effects function correctly when activated
- Duration-based effects have clear timers and expiration
- Visual and audio feedback clearly communicate the active effects
- Active power-ups are indicated on the HUD
- All power-ups are balanced for gameplay
- Each power-up adds strategic value to gameplay
