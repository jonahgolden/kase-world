# Story: Baby Scream Attack

## User Story

**As a player,**  
I want to **use a directional scream attack with my baby character**  
So that I can **damage NPCs and interact with objects in the game world**.

## Acceptance Criteria

### Scream Mechanics

- The baby should be able to scream in the direction they are facing
- Scream attack should have a limited range (approximately 5-10 meters)
- Scream should have a visual representation (sound waves, particles)
- Scream should have a cooldown period to prevent spam (2-3 seconds)
- Scream should have appropriate audio effects

### Damage and Impact

- Scream should cause damage to NPCs within its range and direction
- Damage amount should decrease with distance from the baby
- Scream should be able to impact and affect power-ups
- Impacted objects should have visual feedback (shaking, particles)
- Impacted NPCs should have reaction animations

### Controls and Feedback

- Left mouse button initiates the scream attack
- Player must aim the scream using the camera direction
- There is a simple scope that shows the current camera direction
- Visual indicator should show scream cooldown status
- Screen effect should appear when screaming
- Controller vibration (if supported) when screaming

## Technical Implementation Notes

- Create a Scream trait to track cooldown and power
- Implement a scream system that handles damage calculation and impact
- Use raycasting or cone detection to determine affected entities
- Create visual effects for the scream
- Add audio effects for the scream
- Add impact feedback for affected entities
- Implement UI elements for cooldown status

## Definition of Done

- Player can trigger scream attack with left mouse click
- Scream has appropriate visual and audio effects
- Scream causes damage to NPCs within range and direction
- Scream affects power-ups and other interactive objects
- Cooldown system prevents spam attacks
- UI shows cooldown status clearly
- All impact feedback works correctly

## Dependencies

- Story 1.1: Baby Entity and Basic Movement
- Audio system for scream effects
- Visual effects system
- Basic NPC implementation (for testing)

## Implementation Notes

The baby scream attack has been successfully implemented with the following features:

1. **Scream Trait**: Created a new `Scream` trait to track cooldown, power, range, angle, and active state.

2. **Input Handling**: Updated the `Input` trait and `poll-input` system to detect left mouse button clicks for triggering the scream attack.

3. **Damage System**: Implemented a cone-based detection system in `baby-scream.ts` that applies damage to entities within the scream's range and angle.

4. **Damage Falloff**: Added distance-based damage calculation that reduces the damage as distance increases.

5. **Visual Effects**: Created a `ScreamEffect` component that displays:

   - A translucent cone showing the area of effect
   - Particle effects that animate outward to simulate sound waves

6. **UI Feedback**: Implemented a `ScreamUI` component that displays:

   - Current cooldown status with a progress bar
   - Text indication showing if the scream is READY, ACTIVE, or in cooldown
   - Simple controls hint

7. **Cooldown Mechanism**: Added a 2.5-second cooldown period to prevent spam attacks.

8. **Integration**: Updated the main App component to include the new visual effects and UI elements.

Notes for future enhancements:

- Audio effects for the scream are currently not implemented (marked with TODO)
- NPC reaction animations will be added when NPCs are implemented
- The scream effect on power-ups will be added when the power-up system is implemented
