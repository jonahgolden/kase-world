# Story: Baby Health System

## User Story

**As a player,**  
I want my **baby character to have a health system**  
So that I can **track damage taken and manage survival in the game world**.

## Acceptance Criteria

### Health Mechanics

- The baby character should have a defined maximum health value
- Current health should be represented as a value between 0 and maximum health
- Health decreases when taking damage from NPCs or other hazards
- Health can increase when collecting health power-ups
- When health reaches 0, the game should end (game over state)

### Visual Representation

- A health bar/meter should be visible on the HUD
- The health bar should clearly indicate current and maximum health
- The health bar should change color based on health level:
  - Green: High health (>70%)
  - Yellow: Medium health (30-70%)
  - Red: Low health (<30%)
- Visual feedback when taking damage (screen flash, etc.)
- Visual feedback when gaining health (particles, etc.)

### Damage System

- Different sources of damage should affect health differently
- Brief invulnerability period after taking damage (0.5-1 second)
- Damage sound effects should play when taking damage
- Controller vibration (if supported) when taking damage

## Technical Implementation Notes

- Create a Health trait to track current and maximum health values
- Implement a damage system that applies health reductions
- Implement a healing system for health increases
- Create a health UI component for the HUD
- Add visual and audio feedback systems for damage events
- Implement game over state when health reaches zero

## Definition of Done

- Baby character has functioning health system with appropriate values
- Health bar is visible and accurately reflects health status
- Taking damage properly decreases health with appropriate feedback
- Health power-ups properly increase health with appropriate feedback
- Game ends when health reaches zero
- All visual and audio feedback works correctly

## Dependencies

- Story 1.1: Baby Entity and Basic Movement
- Basic UI system for health display
- Audio system for sound effects

## Implementation Notes

The baby health system has been successfully implemented with the following components:

1. **Health Trait**: Created a `Health` trait that tracks current and maximum health values, invulnerability timer, and damage state.

2. **Health Actions**: Added `applyDamage` and `applyHealing` functions to the actions to manage health changes.

3. **Health System**: Implemented a health system that updates invulnerability timers and checks for game over conditions.

4. **Health UI**: Created a health bar UI component that:

   - Shows current and maximum health
   - Changes color based on health level (green, yellow, red)
   - Provides visual feedback when taking damage

5. **Damage Effects**: Added a screen flash effect when the baby takes damage.

6. **Game Over Screen**: Created a game over screen that appears when health reaches zero.

7. **Testing System**: Added a test system triggered by pressing 'T' key to apply damage for testing purposes.

The health system is fully integrated with the game loop and supports all the required acceptance criteria including proper visual feedback, invulnerability period after taking damage, and game over state.

To test the system, press 'T' in the game to apply 20 damage. After reaching 0 health, the game over screen will appear with a restart button.
