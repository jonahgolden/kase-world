# Story: Crawl and Walk Movement Modes

## User Story

**As a player,**  
I want to **switch between crawling and walking modes for my baby character**  
So that I can **navigate the world at different speeds with appropriate trade-offs**.

## Acceptance Criteria

### Movement Modes

- Two distinct movement modes must be implemented:
  - **Crawling**: Slower movement speed, always available
  - **Walking**: Faster movement speed, limited duration
- The baby should have different animations for each movement mode
- Walking should be approximately 2x faster than crawling

### Walking Duration and Cooldown

- Walking mode can only be active for a maximum of 7 seconds
- After walking limit is reached, the baby must revert to crawling
- A 10-second cooldown timer must pass before walking becomes available again
- Visual indicator should show the remaining walk duration and cooldown status

### Controls

- Default movement mode should be crawling
- Shift key toggles to walking mode (if available)
- The baby should smoothly transition between movement modes

### Movement Characteristics

- Crawling should appear low to the ground with appropriate animation
- Walking should appear upright with appropriate animation
- Camera height should adjust based on movement mode (lower when crawling)

## Technical Implementation Notes

- Create a MovementMode trait to track the current mode, timers, and cooldowns
- Implement a movement system that handles the mode switching and speed changes
- Add visual feedback for mode changes and cooldown status
- Modify camera positioning based on movement mode
- Create animations for both movement modes

## Definition of Done

- Player can toggle between crawling and walking modes
- Walking is limited to 7 seconds with 10-second cooldown
- Movement speeds are appropriately different between modes
- Visual indicator shows walk duration and cooldown status
- Camera position adjusts based on movement mode
- Smooth transitions between movement modes

## Dependencies

- Story 1.1: Baby Entity and Basic Movement
- Basic animation system
- UI components for status indicators
